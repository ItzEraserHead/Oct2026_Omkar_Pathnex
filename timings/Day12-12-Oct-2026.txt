--query "addons[].addonVersions[].addonVersion"

## Helm - Helm is a package manager for Kubernetes that uses Helm charts containing YAML templates and configuration files to deploy, configure, upgrade, roll back, and uninstall applications on a Kubernetes cluster. It simplifies application management by allowing us to manage multiple Kubernetes resources as a single release.

##While updating Wroker Node:
Safe Approach, create new node with latest K8s version and use below, 
If only one node, no other node for creating replacement pod on, Pods will be in Pending State

##Cordon: Cordon means preventing new pods from being scheduled on a node. The pods already running on that node continue running.

##Drain: Drain means safely evicting the existing pods from a node so we can perform maintenance, such as a Kubernetes upgrade. If those pods are managed by Deployments or other controllers, replacement pods can be created and scheduled on other available nodes.
If no other worker node is present/available, pods will be in pending state, application will be in downstate
