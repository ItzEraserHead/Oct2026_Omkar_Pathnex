# Matrix Builds

## jenkins PipeLine -- Matrix Build
you will learn **How to run same build on multiple environment**

pipeline {
    agent any

    environment {
        INSTITUTE_NAME = 'Pathnex'
}

    stages {
        stage('Build matrix') {
            matrix {
                axes {
                    axis {
                        name 'JAVA_VERSION'
                        values '8', '11', '17'
}
}
    stages {
        stage('Build') {
            steps {
                sh 'echo Vuilding with Java $JAVA_VERSION' 
}
}
}
}
}
}
}

## GitLab CI -- Matrix Jobs
you will learn how to **run jobs across multiple environments using matrix**

stages:
  - build

build:
  stage: build
  parallel:
    matrix:
      - JAVA_VERSION: ["8","11","17"]
  image: maven:3.8.1-jdk-17
  script:
    - echo "Building with Java $JAVA_VERSION"
    - java -version
    - mvn --version
