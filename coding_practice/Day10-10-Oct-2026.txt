# Day 10 - Conditions, Route table, Secret, Loops

## Ansible When Condition

---
- name: Install tool based on OS
  hosts: all
  becom: true

  tasks:
    - name: Install htop
      dnf:
        name: htop
        state: present
      when: ansible_facts['os_family'] == "RedHat"

## Caching Dependancies

You will learn hoe to **cache dependancies in GitLab CI**

stages:
  - build

build:
  stage: build
  image: maven:3.8.1-jdk-17
  cache:
    key: maven-cache
    paths: 
      - .m2/repository
    script:
      - git clone https://github.com/Pathnex/sample-java-app.git
      - cd sample-java-app
      - mvn clean compile
